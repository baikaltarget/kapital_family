# Правила
Проверь metadata, canonical, robots, sitemap, доступность контента в HTML, alt и размеры картинок, CLS, внутренние ссылки, корректность schema.org и редиректы. Учитывай конкретный способ сборки/деплоя; запускай доступные проверки и отмечай недоступные.
